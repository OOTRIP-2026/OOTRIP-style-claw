# AI剪贴手账接入与验证（2026-10-27）

## 本轮变化

用户已确认上一版能保存，但不接受矩形相框式拼贴，提供人物居中、独立衣物贴纸、白色轮廓、水彩纸张及手写标注参考。本轮新增默认「AI剪贴手账」方式，沿用手机外框、表单、日期/天气/心情/原文和显式保存流程；未修改实时试衣与Decart次数。

本轮采用 **图像编辑生成**，不是精确语义分割：将用户当前穿搭照片交给百炼qwen-image-2.0，按固定设计提示生成一张人物与可见单品剪贴图。提示要求原人物身份、衣物款式/颜色保持、半身不补腿脚、不可确认单品省略、去掉矩形照片框、细白色轮廓、轻纸张阴影、暖白纸、水彩与少量手绘箭头。参考图仅作为设计依据，未将其人物/海岛/衣服复制进产品，也未把用户提供的参考图片发送给供应商。

图像模型可能重绘面部、衣物细节与遮挡部分，不能宣称精准抠图或原像素保真。生成结果在页面与导出图标记AI剪贴创作，保留原照片供编辑。真正逐件透明分割仍未实现；现有rembg没有接入本轮，也没有下载新模型或调用本地抠图。

## 操作

1. 在项目根目录停止旧HTML服务，重新执行 `npm.cmd run demo:html`，刷新 `http://127.0.0.1:3100/journal`。
2. 上传自己的穿搭照片，制作方式选「AI剪贴手账 · 人物与单品贴纸」。旧草稿可能保留旧方式，可手动切换。
3. 页面显示图像服务就绪后，勾选本次照片处理与额度消耗同意，点击生成。每次一张，不自动重试；通常需要等待，最长本地等待约250秒（供应商请求180秒、结果下载60秒）。
4. 预览后确认保存或下载。修改日期/文字、重新保存、恢复草稿和「调整文字排版」复用已生成画面，不重复调用AI。
5. 只有主动点击「重新生成AI画面」并重新勾选同意、点击生成，才会发起新的图像请求。换照片或旋转照片会清除旧AI画面的关联，避免套用到不同照片。

## 配置（不要发送密钥到聊天）

继续使用根目录本机 `.env` 的 `DASHSCOPE_API_KEY`，需百炼北京地域图像模型权限。qwen3-vl识别额度、Decart积分都不等于qwen-image-2.0图像额度。

仅在百炼控制台核实该图像模型有可用免费额度并已开启“免费额度用完即停”后，填写：

```dotenv
JOURNAL_IMAGE_FREE_ONLY_CONFIRMED=true
JOURNAL_IMAGE_FREE_QUOTA_EXPIRES=控制台实际有效日期（YYYY-MM-DD）
```

有效期按当天起点截止，日期必须晚于当前日期，不要为了绕过校验填写虚假日期。如已有同一模型的 `AVATAR_FREE_ONLY_CONFIRMED` 与 `AVATAR_FREE_QUOTA_EXPIRES` 且仍有效，可复用，无需重复配置。独立JOURNAL字段存在时优先使用。没有可用免费额度时本轮不会自动改付费模式。

可选 `DASHSCOPE_WORKSPACE_ID` 使用控制台的北京工作空间ID；填写后使用官方工作空间端点。未填写保持项目原有dashscope北京端点，不自动切换地域或模型。配置变化需要重启服务。状态接口只输出就绪与脱敏原因，不返回密钥。

## 文件与边界

- `server/src/ai/qwen-avatar.ts`：抽出可复用generateReferenceImage；原generateAvatar的提示词、768×1152与调用行为保留。共用受限结果域名、HTTPS、不跟随重定向、下载不带API Key、大小/PNG尺寸校验。
- `tools/lucy-demo/journal-artwork.ts`：固定剪贴设计提示、图像配置、GET /journal/artwork/status、POST /journal/artwork；同一实例排他运行、同requestId失败也不自动重复。实例最多记100个请求ID保护内存，不代表授权100次付费调用，也不占用/修改Decart批次。
- `journal-server.ts`注册新接口；沿HTML既有Host/Origin/页内nonce保护，不开放任意图像URL或任意模型/提示词输入。
- `web/journal.ts`：模式选择、用途同意、生成进度、AI结果缓存、编辑与新请求区分。图片生成只发送照片，不发送日期、心情、天气或个人文字。
- `web/journal-renderer.ts`：composeArtwork等比例保留整张生成图，日期/emoji/原文在独立下方纸张区绘制，不拉伸、不用文字遮住人物。超过可容纳行数的文字完整保留在记录下方并提示。输出1200×1600PNG。
- `web/journal-model.ts`：向后兼容增加mode=ai-paper、artwork、artworkModel，原照片和AI底图分别持久保存。AI模式历史展示手账封面，不把生成图里的衣物伪装成已分割的真实衣橱单品。
- 原本机纸艺排版与可选区域识别继续可用，AI配置失败不会冒充AI结果。

不自动将生成贴纸导入衣橱。本轮不更换其他AI功能规则，不改小程序界面，不发布公网。

## 官方接口依据

核对[阿里云Qwen图像编辑文档](https://www.alibabacloud.com/help/en/model-studio/qwen-image-edit-api)：支持Base64参考图、文字编辑指令、qwen-image-2.0、单张输出及指定尺寸。原项目北京地址兼容线索见[官方图像模型调用文档](https://help.aliyun.com/en/model-studio/wan-image-generation-finetune-guide)，新工作空间地址按图像编辑文档配置。文档能力不等于当前账号已开通，实际调用尚未验证。


## 2026-10-27 背景回忆与画内记录（待用户真实效果复验）

用户已反馈AI手账整体可用，要求背景局部与色彩参与拼贴、标题与标签手写化、日期/天气/心情/原文融入画面。本轮固定提示改为原背景0至2处局部且总面积不超过15%、照片服装及环境2至4色、动态英文手写标题、简单白名单单品标签、不重复单品。新版提示预留左侧个人记录/右侧天气心情与日期三处画内留白，不再预留横向页脚。生成画面实际是否遵守留白及人物保真仍需用户验证，不能保证模型无文字错误。
