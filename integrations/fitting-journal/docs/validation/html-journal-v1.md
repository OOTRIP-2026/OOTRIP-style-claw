# HTML穿衣手账 V1：实施与迁移评估（2026-10-26）

## 本轮交付

本轮仅修改 HTML 实时试衣下方操作区与穿衣手账；实时视频处理、15秒首帧展示/30秒总限、现有测试次数不变，小程序业务开发继续暂停。

手账已形成可运行闭环：上传或拍照 → 可旋转/移除/重选 → 年月日、选填天气/心情、最多300字原文 → 真实处理阶段动画 → 1200×1600纸艺预览 → 明确保存记录或下载PNG → 历史查看/编辑/重新排版。天气与心情可再次点击取消，不由AI推断。长文字放不进图片时保留完整记录并提示，绝不静默截断。

原始文件Blob、规范化照片、日期、emoji及稳定ID、原文、识别结果、单品裁片、布局坐标、生成图、版本与时间存于当前浏览器IndexedDB。旧版记录仍能查看；没有保存原照片的旧记录编辑时需要重新上传。新版草稿会恢复，生成预览不自动新增历史。保存同一记录更新原ID，按钮防止重复保存。重新排版复用照片与已有裁片，不重新调用AI。分享受浏览器能力限制，不支持时提供下载。

## 实际AI与本机能力边界

- 本机闭环不需要任何AI密钥：图片规范化、方向调整、纸张纹理、胶带/线条/小装饰、按照片横竖比例及单品数量排版、文字绘制、存储、下载均在浏览器执行。
- 可选AI仅识别可见衣物及矩形区域，服务端使用现有百炼接口。用户明确勾选本次发送后才请求；不自动重试。失败后仍可点击“不使用AI，生成本机手账”。
- 百炼所需配置沿用服务端 `DASHSCOPE_API_KEY`、`QWEN_FREE_ONLY_CONFIRMED`、`QWEN_FREE_QUOTA_EXPIRES`。不在HTML填密钥，也无需为纸艺排版购买图像生成模型。
- 单品最多显示4件，过滤明确低可信度/严重遮挡结果。缩略图是真实照片区域裁片，可能含背景，不能称作精确分割或平铺重建。
- 暂未接入人物分割、全身/半身语义排版、精确单品透明抠图、人物区域结构化检测、自动场景提取。当前动态排版按图像宽高及可用单品数量调整；不会生成替代衣服或虚构天气、心情。
- 本轮未执行真实AI调用；识别准确率、复杂照片效果、iPhone相册导出与分享须真机验证。HEIC等不支持格式需转JPEG/PNG/WebP。
- 照片和草稿仅在本机浏览器保存；清理站点数据会丢失记录，应下载重要结果。暂未做账号同步、服务端相册、旧记录批量迁移或正式部署。

## 现有目录是否支持长期目标

结论：足以实现当前HTML闭环，且手账迁移原生小程序可行，不能将HTML/DOM代码原封不动复制过去。

仓库已具备：`miniprogram/services/image-io.ts`、`image-wechat.ts` 图像处理边界；`pages/cutout-editor-validation/index.ts` 和 `pages/fitting-validation/index.ts` Canvas导出调用；`pages/prototype-flow/index.ts` 相册保存调用；已有本地存储与图片管理。不是从零建立能力。

后续原生方案：wx.chooseMedia选择照片 → 保存到受管理本地路径 → Page表单记录信息 → 共享布局规则 → 小程序Canvas2D绘制 → wx.canvasToTempFilePath导出 → wx.saveImageToPhotosAlbum由用户确认保存。大图保存文件路径，不把Base64/Blob塞进页面setData或大JSON；同时处理相册权限、字体差异、画布内存与iOS/Android导出。

现有 `server/src/local-cutout.ts` 与 `server/tools/cutout/` 可用于后续抠图验证，但“已有抠图工具”不等于“穿着人物的每件衣服能准确分割”。此项需独立照片样本、遮挡/肤色/背景边界评估；不要阻塞当前闭环。也未把这个Python工具直接打进HTML服务，避免导入路径与运行环境错误。

个人开发量粗估（基于代码结构，非承诺）：将当前手账闭环迁移到原生并完成双平台基本测试约3–5个工作日；联网鉴权/后端部署/隐私与相册权限整合另约2–4日，取决于已有部署进度；精确人物与单品分割需先做模型验证，至少另留一周实验缓冲，不能保证任意照片效果。当前不开展这些原生工作。

微信官方接口说明尝试访问未成功，本轮迁移评估以仓库已有调用与代码结构为依据；实施时须重新核对当时基础库与正式发布规则。

## 验证与用户操作

本轮 `npm.cmd run check` 通过：68个测试文件、380项测试；`npm.cmd run build` 通过；HTML独立TypeScript检查通过。Chrome隔离测试使用合成照片、所有HTTP拦截，无相机/真实供应商请求：验证3:4预览、显式保存、防重复点击、原文件/原文保存、编辑还原、长文字保留、重新排版、刷新草稿、AI失败可本机生成、存储失败保留预览/重试。截图仅在ignored output中，不是用户真实照片效果验收。

1. 在当前运行HTML服务的终端按Ctrl+C，然后在项目根目录执行 `npm.cmd run demo:html`，刷新 `http://127.0.0.1:3100`。无需重置测试次数。
2. 打开穿衣手账，上传照片、选日期，天气/心情可以留空或点选后取消，输入含换行的文字。
3. 先不勾AI，点击生成：应显示真实照片纸艺图；确认保存后返回才出现历史。
4. 打开记录编辑、旋转照片或换排版、下载PNG。长文字应完整显示在图片下方并保存在记录中。
5. 仅在你需要验证真实单品识别时勾选同意再生成；这一步可能消耗百炼额度，本轮没有替你执行。

用户对本轮视觉与真实照片的验收尚待反馈。
