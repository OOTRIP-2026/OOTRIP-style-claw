# 接手AI必读

先完整阅读HANDOFF.md和MODULE-MAP.md，再按用户要求修改。当前交付范围只有HTML手机演示版实时试衣与穿衣手账；其他业务交由组员维护，不重建整体App。

1. 先检查目标项目框架、路由、导航、衣橱DTO、存储、服务入口和双方变更，再做对应接线；不要用本包package.json或AGENTS.md覆盖整体项目同名文件。
2. 实时试衣归试衣间/实时试衣区域；穿衣手账归我的/穿衣手账区域。本包双Tab与手机壳只是演示承载，合并后使用整体导航，不增加第三套衣橱。
3. 密钥只在服务端。不要读取、输出、复制真实.env、照片、开发令牌。不开启自动真实调用；不重置测试预算、不自动重试费用请求。
4. 用目标项目衣橱适配store.ts；保留套装互斥、同类单选。手账临时单品不自动加入衣橱；手账人工选择允许不同记录需求，最多4件。
5. 保留旧IndexedDB、草稿、原图与AI底图；artworkVersion缺省3，新生成4。不能全量清库或将旧结果误套新版画内布局。
6. 先交付可运行的组合版本、明确变更和验证证据。真实API、摄像头与费用测试由用户在页面主动操作。不要将历史测试通过视为本包最新变更已通过。
7. 迁回小程序是后续移植任务：DOM、Canvas、IndexedDB、浏览器WebRTC SDK需要适配，不直接复制成WXML，也不声称已完成原生实时试衣整合。
